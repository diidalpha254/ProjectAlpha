# 📊 Project Alpha - Advanced Market Intelligence Platform

## Overview

Project Alpha is an advanced Deriv Match/Differ Market Intelligence Platform designed to analyze live Deriv tick data and provide statistical market insights.

### ⚠️ Important Disclaimer

This platform provides statistical market insights for **educational and informational purposes only**. It does NOT claim to predict future outcomes or guarantee winning trades.

## Features

### Core Analytics
- 📊 Live digit frequency analysis
- 🔥 Hot digit detection
- ❄️ Cold digit detection
- 🔄 Digit transition probability matrix
- 🎯 Markov Chain analysis
- 🎲 Entropy/randomness analysis
- 📉 Volatility measurement
- 🎯 Confidence scoring

### Market State Engine
- 🌊 Calm
- 🎲 Random
- 📈 Trending
- 🌪️ Volatile
- 🌀 Chaotic
- ↔️ Mean Reverting
- ⚡ Momentum Driven

### Advanced Features
- 🔄 Historical replay mode
- 📝 Tick recording
- 📥 Export data to CSV/JSON/Excel
- 📸 Screenshot capability
- 🔍 Search historical sessions
- 🔔 Real-time notifications
- 🎨 Dark/Light theme
- 🔌 Modular plugin architecture

## Installation

1. Clone the repository
2. Create virtual environment
3. Install dependencies: `pip install -r requirements.txt`
4. Run: `streamlit run app/main.py`

## Technology Stack

- **Frontend**: Streamlit
- **Backend**: Python
- **WebSocket**: Deriv WebSocket API
- **Database**: SQLite
- **Analytics**: Pandas, NumPy, Scikit-learn
- **Visualization**: Plotly
